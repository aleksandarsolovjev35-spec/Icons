# v1 — детализированный digital art

Первая версия набора: painterly digital art по мотивам листов
`RPG Loot Icons 01`. На 40 px в инвентаре детали сливаются — поэтому набор
заменён силуэтами (см. `style/bake-off-2026-10-18.png`).

Оставлено как референс: эти же артетики пригодятся, если понадобится
«детальная» версия отдельных предметов.
