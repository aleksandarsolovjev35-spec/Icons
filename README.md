# Loot Icons for D&D 5e

Шаблонная библиотека иконок предметов для **Foundry VTT** в стиле *digital art*.

К предметов в D&D 5e — сотни, а уникальных форм — несколько десятков. Поэтому
здесь не «одна картинка на каждый предмет», а **набор архетипов**: один нарисованный
флакон закрывает зелье лечения, зелье огня, яд и антидот. Модуль сам подбирает
иконку предмету по названию, а редкость подсвечивает в рантайме — без единой
дополнительной картинки.

```
+----------------------------------------------+   +------------------------------+
|  Potion of Healing        ->  flask-potion   |   |  Potion of Healing           |
|  Bottle of Poison         ->  vial           |   |  [icon]  Potion of Healing   |
|  Treasure Chest           ->  chest          |   |          Common              |
|  Gold Ingot               ->  ingot          |   |                              |
+----------------------------------------------+   +------------------------------+
```

## Что внутри

| | |
|---|---|
| **18 архетипов** | 7 категорий: consumables, adventuring, containers, treasure, materials, nature, food |
| **Формат** | WebP 200×200, прозрачный фон, 6–15 КБ |
| **Автоприсвоение** | exact → keywords → type; переименовал предмет — иконка обновилась |
| **Редкость** | common → uncommon → rare → very rare → legendary → artifact: подсветка на CSS, ассеты не дублируются |
| **Совместимость** | Foundry VTT 12–14, система dnd5e 3.x–5.x |

## Установка

### Вручную

1. Склонировать репозиторий в `Data/modules/loot-icons-dnd5e`.
2. Включить модуль **Loot Icons for D&D 5e** в настройках мира.

### Через Module Manager

В `Manage Modules → Install Module` вставить:

```
https://raw.githubusercontent.com/aleksandarsolovjev35-spec/Icons/main/manifest.json
```

### Через макрос

```js
// назначить иконки всем предметам мира (актёры + items)
await LootIcons.assignAll();

// то же, но ещё и по всем компендиумам (медленно, зато полно)
await LootIcons.assignAll({ compendiums: true });

// назначить иконку конкретному предмету
await LootIcons.assignToItem(actor.items.get("abc123"));

// открыть пикер архетипов для предмета
await LootIcons.pickIcon(actor.items.get("abc123"));

// посмотреть, что вообще есть в библиотеке
LootIcons.list("treasure");  // -> [{ id, path }, ...]
LootIcons.categories();       // -> [{ id, label, icons: [...] }, ...]
```

Иконки видны и в штатном пикере файлов Foundry — на вкладке модуля.

### В интерфейсе

* На **листе персонажа** — кнопка с волшебной палочкой проставляет иконки всем
  предметам инвентаря.
* На **листе предмета** — кнопка с картинками открывает пикер архетипов:
  сетка иконок по категориям, клик — и предмет получает выбранную иконку.
* Редкость подсвечивает иконку прямо в инвентаре (зелёный / синий / фиолетовый /
  золотой / красный).

## Как это устроено

```
manifest.json          манифест модуля
icons/<категория>/*.webp   сами иконки
data/icons.json        сгенерированный индекс библиотеки
data/rules.json        словарь: exact / keywords / type
scripts/module.js      хуки, автоприсвоение, пикер, подсветка редкости
scripts/matcher.js     чистая логика подбора (тестируется без Foundry)
styles/loot-icons.css  подсветка редкости
styles/icon-picker.css стили пикера
templates/             шаблон пикера
docs/STYLE-GUIDE.md    промпт-шаблон и постобработка
docs/TAXONOMY.md       категории и правила именования
tools/                 пайплайн сборки библиотеки
```

### Подбор иконки

1. **exact** — точное совпадение нормализованного названия (`Potion of Healing`).
2. **keywords** — сумма весов совпавших слов. Обычное слово весит 1, «сильное»
   (в блоке `strong`) — 3. Поэтому `Bottle of Poison` уходит на склянку с ядом,
   а не на бутылку, а `Oil Lantern` — на фонарь, а не на масло.
3. **type** — запасной вариант по типу предмета (`consumable` → флакон).
4. Ничего не подошло — остаётся системная иконка dnd5e.

Иконка **не перезаписывает** то, что ГМ назначил руками: правило срабатывает
только для системных плейсхолдеров и для иконок самой библиотеки.

### Редкость

`data-rarity` на строке предмета + CSS. Обычный предмет — без подсветки,
необычный — зелёный, редкий — синий, очень редкий — фиолетовый, легендарный —
золотой, артефакт — красный. Добавить новую редкость = одна строка CSS, ассеты
трогать не нужно.

## Разработка

```bash
python3 -m venv .venv && .venv/bin/pip install pillow numpy scipy
.venv/bin/pip install rembg onnxruntime        # опционально, для вырезания фона

# 1. положить сырые картинки в src/raw/<id>.png
# 2. вырезать фон, нормализовать кадр, собрать webp
.venv/bin/python tools/process_library.py

# 3. пересобрать индекс и проверить правила
.venv/bin/python tools/build_library.py

# 4. прогнать юнит-тесты правил
node tools/test_rules.mjs

# 5. собрать контакт-лист для ревью
.venv/bin/python tools/contact_sheet.py
```

Пайплайн нарисован так, чтобы результат был **воспроизводимым**: сырые картинки
лежат в `src/raw` (в git не попадают), обработанные мастера — в `src/processed`,
в репозиторий едут только итоговые 200×200 webp.

Подробности промпта и постобработки — в [docs/STYLE-GUIDE.md](docs/STYLE-GUIDE.md).
