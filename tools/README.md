# Апскейл иконок до 256×256

`upscale_256.py` — конвейер повышения разрешения исходных PNG (~147–155 px) до 256×256.

## Что делает

1. **Пересчёт в линейный свет** (точная кривая sRGB, IEC 61966-2-1).
   Ресемплинг в линейном пространстве убирает тёмные ореолы и «грязные» полутона,
   которые появляются при обычном ресайзе в гамма-пространстве.
2. **Lanczos-4 до 256×256** — даёт больше всего деталей без звонa по сравнению с cubic/bicubic.
3. **Edge-aware unsharp только по каналу L (LAB)**:
   - порог 2/255 не даёт усиливать шум и JPEG-артефакты,
   - добавка детали ограничена ±0.10, поэтому крутые края становятся резче,
     но белых ореолов и клиппинга в бликах нет,
   - цветность (a/b) не трогается — без цветных каёмок.
4. **Lossless PNG** (`optimize=True, compress_level=9`), с упорядоченным дизерингом
   перед квантизацией в 8 бит — градиенты не полосят.

Проверялись альтернативы: ESPCN×2, FSRCNN×2, EDSR×2/×3 (`cv2.dnn_superres`).
На стилизованной рисованной графике neural-модели, обученные на фото, дают
не более резкий, но чуть «замыленный»/пластиковый результат, поэтому в финальном
конвейере используется Lanczos в линейном свете + ограниченный unsharp.
EDSR×3 отнимал ~6.5 с на иконку — 11300 иконок это ~20 часов на 2 ядрах.

## Запуск

```bash
pip install pillow numpy opencv-python-headless
python3 tools/upscale_256.py --src . --dst icons_256 --jobs 2
```

Скрипт рекурсивно обходит все подпапки, сохраняет структуру каталогов,
кладёт результат в `icons_256/<та же папка>/<то же имя>.png`.
Полезные флаги: `--src "<папка>"` (только часть коллекции), `--skip-existing`,
`--amount` / `--radius` (сила и радиус шарпа).

## Результат

- Полный прогон: **11 300 PNG, 256×256 RGB, ≈870 МБ** (~72 КБ на иконку).
- В репозитории лежит образец — 15 коллекций (1 500 иконок, ≈114 МБ) в `icons_256/`,
  остальное генерируется той же командой (полный прогон ~6 минут на 2 ядрах).
- Сравнение «до / после» (слева nearest-апскейл оригинала, справа результат): `tools/preview_256.png`.

Для веба можно сэкономить ~7× по весу: WebP q92 даёт ~10 КБ на иконку (≈115 МБ на весь набор)
при визуально неотличимом качестве.
