# Таксономия иконок

Библиотека построена как **шаблоны**, а не как набор «одна иконка на предмет».
Предметов в D&D 5e (SRD 5.1 / 5.2 + homebrew) порядка тысячи, а уникальных
*форм* — порядка шестидесяти. Поэтому иконка описывается тремя слоями:

| Слой | Что меняется | Пример |
|------|--------------|--------|
| **Форма** | силуэт-архетип | флакон, свиток, сундук, слиток |
| **Вариант** | материал и форма в рамках архетипа | флакон: стекло / кость / медь; слиток: железо / серебро / золото |
| **Акцент** | цвет, свечение, редкость | common → uncommon → rare → very rare → legendary → artifact / cursed |

Слой **акцента не тиражируется в ассетах**: цвет и свечение rarity
подставляются в рантайме CSS-ом (см. `styles/loot-icons.css`). Благодаря
этому добавление новой редкости не требует перерисовки библиотеки.

## Категории

| Категория | id префикс | Что закрывает |
|-----------|-----------|---------------|
| Consumables | `consumables/` | зелья, масла, яды, свитки, зелья из домашних правил |
| Adventuring | `adventuring/` | факелы, фонари, верёвка, книги, инструменты, припасы |
| Containers | `containers/` | рюкзаки, сундуки, мешки, бочки, ящики |
| Treasure | `treasure/` | слитки, монеты, самоцветы, кольца, украшения |
| Materials | `materials/` | руда, кристаллы, дерево, кожа, кость, пряжа |
| Nature | `nature/` | травы, грибы, ягоды, цветы, перья, шкуры, кости |
| Food | `food/` | хлеб, сыр, мясо, рыба, фрукты, выпечка, эль |
| Weapons | `weapons/` | кинжалы, мечи, топоры, древковые, луки, посохи |
| Armor | `armor/` | шлемы, кирасы, щиты, сапоги, плащи |
| Magic | `magic/` | палочки, сферы, реликвии, маски, самоцветы с чарми |

Пилотная партия закрывает первые семь категорий частично — остальное
добирается следующими итерациями.

## Соглашение об именах

* `category/name` — путь файла, только lowercase, через дефис.
* `name` — устойчивый идентификатор иконки, используется в словаре
  автоприсвоения (`data/rules.json`).
* Идентификатор не содержит номеров версий: если иконку придётся
  перерисовывать, путь остаётся прежним.

## Словарь автоприсвоения

`data/rules.json` хранит правила трёх видов:

```json
{
  "exact":   { "potion of healing": "consumables/flask-potion" },
  "keywords": [ { "icon": "consumables/flask-potion", "words": ["potion", "elixir"] } ],
  "type":    { "consumable": "consumables/flask-potion" }
}
```

Порядок применения: **exact → keywords → type**. Если ни одно правило не
сработало, остаётся системная иконка `systems/dnd5e/icons/svg/items/loot.svg`.
